# Captain incoming-request sound

Place the approved, royalty-free Captain ringtone at `assets/sounds/incoming_ride.wav`.

It is intentionally not included yet: no suitable audio asset exists in this repository, and this project must not invent or download one. When the file is added, configure it in the Captain-only `expo-notifications` plugin entry and use its filename in `INCOMING_RIDE_NOTIFICATION_SOUND`.
